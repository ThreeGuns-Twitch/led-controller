# LED Controller

Kostenlose Windows-App zum Steuern von Bluetooth-LED-Strips und -Lampen – mit Musikmodus, Bildschirm-Licht,
Symbol im Infobereich, Autostart und einem Stream-Deck-Plugin mit Live-Status.

## Download

Die neueste Version gibt es unter **[Releases](../../releases/latest)**: `LED-Controller-Setup-<Version>.exe`
herunterladen und ausführen. Ist die App installiert, meldet sie neue Versionen selbst.

Falls Windows „Unbekannter Herausgeber“ meldet: „Weitere Informationen“ → „Trotzdem ausführen“.

## Unterstützte Geräte

Govee (Bluetooth-Modelle), ELK-BLEDOM / MELK (Lotus Lamp X, duoCo), Triones / HappyLighting, BJ_LED / MohuanLED,
SP110E. Nicht unterstützt: Tuya / Smart Life / Elesion (verschlüsselt), reine WLAN- oder Infrarot-Lichter.

Voraussetzung: Windows 10 oder 11 mit Bluetooth.
